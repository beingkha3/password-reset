Password Reset Flow

A secure password reset workflow built with Node.js, Express, MongoDB, React, and Bootstrap.

API Endpoints

MethodEndpointDescription
POST/api/auth/forgot-passwordGenerate and email a reset link
GET/api/auth/reset-password/:tokenVerify a reset token
POST/api/auth/reset-password/:tokenSet a new password

Frontend Routes

RouteDescription
/forgot-passwordRequest a reset link
/reset-password/:tokenVerify token and set a new password
/loginLogin handoff screen after reset

Token Storage

The raw reset token is emailed to the user. The database stores only a SHA-256 hash plus an expiry timestamp.
